# Obsidian Ecosystem Radar

A public site that tracks the Obsidian community-plugin ecosystem and rebuilds itself every Monday.
It answers four questions with data: what is new, what is growing, which loved plugins are looking
for maintainers, and where the gaps are.

> Status: under construction. See `STATE.md`, `NEXT.md` and `PROGRESS.md`. Run `./score` to see which rungs of the ladder pass.
